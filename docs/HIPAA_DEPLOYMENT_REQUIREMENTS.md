For services deliberately excluded from PHI, verify routing and data minimization rather than assuming exclusions hold. Audit actor/patient linkage can itself be sensitive. Frontend hosting and PHI backend may use different approved environments; browser API configuration must not require a domain rewrite to move the backend.

Release evidence needed: written risk analysis and accountable owners; permitted data categories; identity/provisioning/MFA policy; access reviews; incident/breach procedures; logging and retention policy; backups with demonstrated restore; deletion/export workflows; key management; dependency/security assessment; clinician review workflow and licensing checks. Contractual/regulatory determinations belong to qualified reviewers and executed agreements. None are inferred from a product webpage or from implementing RLS.
